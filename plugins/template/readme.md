# Example Host

这是 Picora 原生插件的开发模板，**example.com 为占位地址，没有真实上传服务**。安装此模板只能检查包结构，不能证明真实上传成功。

## 作者修改清单

- 修改 plugin.json 的 ID、名称、作者、版本、主页、源码仓库。
- 修改 uploader.json 的网络权限、接口 URL、认证、文件字段与响应路径。
- 替换 assets/icon.svg，并说明所用资源的许可。
- 把本页改成实际服务介绍、配置教程、大小限制和常见错误说明。
- 保留模板的 MIT 许可；为新增部分添加适用的版权说明。

## 使用教程示例

1. 到服务网站获取上传 Token。
2. 在“仓库 → 插件中心”安装插件 ZIP。
3. 在图床列表添加本插件配置，填写 Token。
4. 在上传页选择该配置并上传测试图片。

同一插件可创建多组图床配置，分别保存凭据。不要将真实 Token 写进插件程序或打包到 ZIP。

![示例图标](assets/icon.svg)

## 错误排查

- 401：检查 Token 与认证请求头。
- 找不到图片链接：对照实际 JSON 响应修正 response.url。
- 无权访问主机：检查 permissions.network 与请求 URL。
- 更多说明：阅读 Picora 仓库中的插件开发文档。
