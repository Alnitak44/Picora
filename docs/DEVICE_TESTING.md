# 设备验收

包名：`io.github.alnitak44.picora`。

```sh
adb install -r path/to/Picora.apk
adb logcat
```

验收范围：

- 上传：相册、相机、链接、系统分享、批量上传和失败重试。
- 配置：默认目标、临时切换、同图床多配置、导入导出。
- 相册：三种布局、筛选、多选、复制与删除。
- 插件：安装、覆盖更新、停用、资源图标和离线教程。
- Markdown 迁移：覆盖/另存、失效链接、取消、冲突检测和原文恢复。
- 主题：浅色、深色、系统切换与重启后的持久化。
- 异常：错误凭据、断网、超时、存储不足和诊断日志。

反馈记录应用版本、设备、Android 版本、复现步骤及诊断编号。
